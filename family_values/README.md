# 🧭 家族の価値観マップ（初期構築 / MVP）

**一緒に暮らす前後の、二人の価値観のすり合わせ** を支援する AI アプリの試作です。
同棲・入籍・出産などの節目に、二人で 30 分。

診断アプリでも、相性診断でもありません。
本当に作りたいのは、**“対話の共通言語”** です。
価値観・強み・ストレスポイントは、その共通言語をつくるための手段にすぎません。

最終的にユーザーに得てほしいのは、
「相手が間違っている」ではなく、
**「相手はこういう世界で生きているんだ」** という理解です。

### なぜ「衝突してから」ではなく「その前」なのか

このアプリは、作者自身が夫婦で価値観のすれ違いに直面した経験から生まれました。
ただ、いちばん揉めている最中は、AI の整理さえ「ほら AI もこう言っている」と
**相手を言い負かす道具**になりかねません。そのリスクを避けるため、入口は
**平時（暮らし始める前後）の前向きなすり合わせ** に置いています。

とはいえ、すでにすれ違って一人で悩んで来た人も締め出しません。
その人は「🫱 相手を想像する（ひとり）」から始められます（相手の内面は断定せず、
あくまで仮説として扱います）。

---

## AI の立ち位置（最重要）

- AI は **答えを出しません**。
- AI は **ジャッジしません**。「あなたが正しい」とも言いません。
- AI は **説得しません**。相手を変えさせようとしません。
- AI の役割は **“視点を増やすこと”** だけです。

## 見せ合わない、翻訳して返す（プライバシー設計）

自分の生の価値観をそのまま相手に見られるのは、抵抗があって当然です
（点数がそのまま「証拠」になり、データが武器になりうる）。だからこのアプリは、
**お互いの生の点数・カードを見せ合いません**。

- 各自の詳しいプロファイルは **本人だけ** が見る。
- 二人ぶんのデータは合わせて解釈するが、画面に出すのは
  **その人に宛てた“私信”だけ**（🧭 読み解き）。
- あなたには「相手はこういうことを大事にしているみたい」と **翻訳された言葉** で届く。
  相手には、相手に宛てた別の読み解きが届く。**生の数値は相手に渡らない。**

---

## 使い方の流れ

おすすめは **二人でやる** こと。相手がまだなら、一人でも始められます。

```
（二人で）🪞 自分を知る ×2人 ─▶ 👨‍👩‍👧 二人で見る ─▶ 🧭 読み解き（各自に宛てた私信）─▶ 💬 対話支援
（一人で）🪞 自分を知る ─▶ 🫱 相手を想像する（ひとり・仮説）─▶（手応え）─▶ 相手にも診断してもらう
```

## 機能

| | 機能 | 内容 |
|---|---|---|
| 🪞 | 自分を知る | 12 の価値観カードで、**価値観・強み・ストレスポイント・意思決定傾向**を可視化（本人だけが見る） |
| 👨‍👩‍👧 | 二人で見る | 生の点数は見せ合わず、**共通して大切そうなこと（対話の足場）だけ** を確認 |
| 🧭 | 読み解き | 二人ぶんを解釈し、**「あなたはどちら？」で選んだ本人に宛てた私信** を返す。相手の生データは出さず翻訳して伝える。テーマは**同棲・二人暮らしの定番パック**から選べる |
| 💬 | 対話支援 | 答えではなく、**お互いに聞き合う「問い」** を提案（同上のテーマパック対応） |
| 🫱 | 相手を想像する（ひとり） | 相手がまだのとき用。相手が守ろうとしていた *かもしれない* 価値観を **仮説として** 提示し、**相手に確かめる問い** に変える |

> 🫱 相手を想像するモードでは、相手はこの場にいません。だから AI は
> 相手の内面を **断定しません**。すべて「〜かもしれない」という仮説として出し、
> 最後は必ず「本人に確かめる問い」に着地させます。
> 目的は相手を言い当てることではなく、あなたの視野を広げることです。

## 動かし方

```bash
pip install -r ../requirements.txt   # リポジトリ共通の依存
streamlit run app.py
```

### AI キー（任意）

`ANTHROPIC_API_KEY` を設定すると、③ AI 分析・④ 対話支援が
Claude で生成されます。**未設定でも動きます**（ルールベースの簡易版に
自動フォールバックし、可視化と問いの提案はそのまま使えます）。

- 環境変数、または `.env`（`family_values/.env`）に記述
- Streamlit Cloud の場合は `.streamlit/secrets.toml` の `ANTHROPIC_API_KEY`

```
ANTHROPIC_API_KEY=sk-ant-...
```

### データ保存 / 復元キー（任意）

`DATABASE_URL`（Postgres）を設定すると、家族の記録が **復元キー** に
紐づいて保存され、リロードしても復元できます（既存 Hub と同じ方式）。

- **復元キー** = ブラウザに紐づく 32 桁 hex。`?u=<key>` で切り替わります。
- **家族 = 1 つの復元キー**。その配下に各メンバーの行が保存されます。
- テーブル `family_value_profiles` は初回接続時に自動作成されます
  （手動マイグレーション不要）。
- **未設定でも動きます**：その場合はセッション内のみ（リロードで消える）。

```
DATABASE_URL=postgresql://user:pass@host:5432/dbname
```

## 現在の MVP の割り切り

- 保存は `DATABASE_URL` があれば復元キー単位で永続化、無ければセッション内のみ。
- 価値観カードは 12 種の初期セット。実運用の中で見直していく前提です。
- 意思決定傾向は「タイプ判定」ではなく、上位価値観からの**緩い傾き**の提示です。

### 方向性のメモ（軸の選択）

検討した 2 つの入口:

- **軸1：CBT × 夫婦・自己バイアス除去（衝突後の修復）** — 実体験に近く刺さりも
  強いが、揉めている最中は AI の整理が相手への武器になりうる。この武器化リスクを
  避けるため、**主軸には置かない**。ただし「🫱 相手を想像する（ひとり）」に、
  相手を断定しない仮説どまりの形で最小限の思想だけ残す。
- **軸2：同棲・節目のすり合わせ（平時・予防）** ← **こちらを主軸に採用**。
  前向きな共同作業なので二人がそろいやすく、武器化リスクも低い。弱点は「引き」の
  弱さ（あったらいいな止まり）なので、**平時ではなくライフイベント**
  （同棲・入籍・出産）に貼り付けて動機の高い瞬間を狙う。

将来の深掘り候補：テーマパックの拡充、記録の振り返り（再発防止的な使い方）、
CBT の型（認知の歪み）をソロモードに“仮説として”そっと足す、など。

> これはセルフヘルプの補助ツールであり、医療・心理の診断ではありません。
