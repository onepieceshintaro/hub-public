# 🧭 家族の価値観マップ（初期構築 / MVP）

家族の価値観を可視化し、**対話を支援する** AI アプリの試作です。

診断アプリでも、相性診断でもありません。
本当に作りたいのは、**“対話の共通言語”** です。
価値観・強み・ストレスポイントは、その共通言語をつくるための手段にすぎません。

最終的にユーザーに得てほしいのは、
「相手が間違っている」ではなく、
**「相手はこういう世界で生きていたんだ」** という理解です。

---

## AI の立ち位置（最重要）

- AI は **答えを出しません**。
- AI は **ジャッジしません**。「あなたが正しい」とも言いません。
- AI は **説得しません**。相手を変えさせようとしません。
- AI の役割は **“視点を増やすこと”** だけです。

---

## 使い方の流れ：まず一人で → 手応えがあれば二人で

相手がいなくても始められます。一人で価値が出るところから入り、
準備ができたら相手を巻き込む、という **ソロ起点** の設計です。

```
🪞 自分を知る ──▶ 🫱 相手を想像する（ひとり） ──▶（手応え）──▶ 👨‍👩‍👧 家族で見る ─▶ 🧭 AI分析 ─▶ 💬 対話支援
        ひとりで完結する範囲                              相手にも診断してもらってから
```

## 機能

| | 機能 | 内容 |
|---|---|---|
| 🪞 | 自分を知る | 12 の価値観カードで、**価値観・強み・ストレスポイント・意思決定傾向**を可視化 |
| 🫱 | 相手を想像する（ひとり） | 相手が守ろうとしていた *かもしれない* 価値観を **仮説として** 提示し、**相手に確かめる問い** に変える。相手の登録は不要 |
| 👨‍👩‍👧 | 家族で見る | 家族全員の結果を **並べて** 見比べる |
| 🧭 | AI 分析 | 違いを「**それぞれが何を守ろうとしているか**」という共通言語に翻訳 |
| 💬 | 対話支援 | 答えではなく、**お互いに聞き合う「問い」** を提案 |

> 🫱 相手を想像するモードでは、相手はこの場にいません。だから AI は
> 相手の内面を **断定しません**。すべて「〜かもしれない」という仮説として出し、
> 最後は必ず「本人に確かめる問い」に着地させます。
> 目的は相手を言い当てることではなく、あなたの視野を広げることです。

## 動かし方

```bash
pip install -r ../requirements.txt   # リポジトリ共通の依存
streamlit run app.py
```

### AI キー（任意）

`ANTHROPIC_API_KEY` を設定すると、③ AI 分析・④ 対話支援が
Claude で生成されます。**未設定でも動きます**（ルールベースの簡易版に
自動フォールバックし、可視化と問いの提案はそのまま使えます）。

- 環境変数、または `.env`（`family_values/.env`）に記述
- Streamlit Cloud の場合は `.streamlit/secrets.toml` の `ANTHROPIC_API_KEY`

```
ANTHROPIC_API_KEY=sk-ant-...
```

### データ保存 / 復元キー（任意）

`DATABASE_URL`（Postgres）を設定すると、家族の記録が **復元キー** に
紐づいて保存され、リロードしても復元できます（既存 Hub と同じ方式）。

- **復元キー** = ブラウザに紐づく 32 桁 hex。`?u=<key>` で切り替わります。
- **家族 = 1 つの復元キー**。その配下に各メンバーの行が保存されます。
- テーブル `family_value_profiles` は初回接続時に自動作成されます
  （手動マイグレーション不要）。
- **未設定でも動きます**：その場合はセッション内のみ（リロードで消える）。

```
DATABASE_URL=postgresql://user:pass@host:5432/dbname
```

## 構成

```
family_values/
├── app.py          # Streamlit エントリ（自分を知る〜対話支援を 1 画面に）
├── value_cards.py  # 価値観カード定義（＝共通言語の語彙）
├── profile.py      # レーティング → プロファイル／家族比較（純粋ロジック）
├── ai_engine.py    # Claude 分析・対話提案／相手の想像（未設定時はルールベース）
├── storage.py      # 復元キー＋Postgres 永続化（未設定時はセッションのみ）
└── README.md
```

---

## 現在の MVP の割り切り

- 保存は `DATABASE_URL` があれば復元キー単位で永続化、無ければセッション内のみ。
- 価値観カードは 12 種の初期セット。実運用の中で見直していく前提です。
- 意思決定傾向は「タイプ判定」ではなく、上位価値観からの**緩い傾き**の提示です。

### この先の可能性（未実装・メモ）

- **結婚初期**（衝突が起きる前に、お互いの価値観を知っておく）や
  **再発防止**（過去のすれ違いのパターンを振り返る）といった、
  “平時に使う” 入口も考えられます。ただし人が手に取る動機は
  「今すれ違っている最中」に集中しがちで、平時ユースケースは
  多くない見込み。まずはソロ起点の芯を磨くことを優先します。

> これはセルフヘルプの補助ツールであり、医療・心理の診断ではありません。
